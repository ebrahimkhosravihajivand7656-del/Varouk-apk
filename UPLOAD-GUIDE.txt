نسخه نهایی یکپارچه واروک

1) قبل از جایگزینی، از Repository فعلی GitHub یک Backup بگیر.
2) فایل‌ها و پوشه‌های این بسته را با ساختار Repository جایگزین کن.
3) پوشه db، public و mobile را در سطح ریشه نگه دار.
4) Commit changes بزن.
5) Render به‌صورت خودکار Deploy می‌کند.
6) در Render > Environment مقادیر DATABASE_URL، JWT_SECRET، ADMIN_USER و ADMIN_PASSWORD را بررسی کن.
7) بعد از Live شدن، این آدرس‌ها را تست کن:
   /api/health
   /admin
   /

هشدار:
- PostgreSQL را حذف نکن.
- DATABASE_URL را تغییر نده مگر اینکه عمداً دیتابیس جدید ساخته باشی.
- رمز مدیر را در کد یا GitHub ننویس؛ فقط Environment.
- برای APK فقط بعد از مشخص شدن دامنه نهایی Render مقدار API_BASE_URL را در mobile/src/config.js تنظیم کن.
